# عرض «سديد» للإدارة التنفيذية

`سديد-عرض-تنفيذي.pptx` — أربع عشرة شريحة بالعربية (من اليمين إلى اليسار)، مع ملاحظات
المتحدّث في كل شريحة.

> **المرحلة.** العرض كلّه عن مرحلة **الموافقة المسبقة (Pre-Authorization)**: احتمال
> ألّا تصدر الموافقة على الطلب كاملةً **قبل رفعه للضامن**. الأرقام المالية فيه هي
> **المبلغ المطلوب مقابل المبلغ المعتمد** — لا التحصيل النقدي، ولا مرحلة المطالبات (Claims).

## مصدر كل رقم

كل رقم في العرض مشتقّ من مخرجات التدريب في `model/artifacts/` — لا رقم مُقدَّر يدوياً
عدا **نسبة الإصلاح**، وهي الافتراض التشغيلي الوحيد وتُعرض كنطاق (20٪ إلى 50٪) لا كرقم
واحد. لإعادة اشتقاق اقتصاديات العرض:

```bash
python3 deck/economics.py
```

يطبع مسار القيمة، ونسبة التسرّب الحالية، وجدول الحساسية السنوي، والعائد لكل ساعة مراجعة.

**متوسط قيمة الطلب غير متاح في بيانات النموذج**، فعُرض العائد كجدول حساسية عبر أربع
قيم للفاتورة وأربع نسب إصلاح — تُسقِط عليه الإدارة رقمها الفعلي مباشرة.

## إعادة بناء الملف

```bash
npm install pptxgenjs
cd deck && node build_deck.js
```

`sadeed.png` و`cluster.png` نسختان نقطيّتان من `assets/sadeed-logo.svg` و`assets/logo.png`
(pptx لا يقرأ SVG). اللقطات تُقرأ من `docs/img/`.

## ملاحظة على العربية في PowerPoint

النصّ العربي في العرض يتجنّب عمداً وضع `%` أو `+` ملاصقاً لرقم داخل جملة عربية، لأن
ترتيب المحارف ثنائي الاتجاه يقلبها عند العرض. الأرقام الكبيرة المستقلّة تُكتب كما هي،
و`+4.2%` مغلّفة بمحارف اتجاه صريحة.
