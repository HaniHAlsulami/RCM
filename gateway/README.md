# بوّابة «سَنَد» لمفتاح Gemini — نشرٌ في خمس دقائق

الهدف: **كل من يفتح رابط المنصّة يستطيع استخدام التوليد اللغوي، ولا يستطيع أحد قراءة
المفتاح** — لأنه لا يغادر خادم البوّابة أصلاً.

> **لماذا لا يوضع المفتاح في الموقع نفسه «مشفَّراً»؟**
> المنصّة صفحات ثابتة تُرسل بحذافيرها إلى متصفّح كل زائر. أي تشفير داخلها يجب أن
> يُرفق معه ما يفكّه ليُستخدم المفتاح — فيستطيع كل زائر فكّه بالطريقة نفسها.
> التشفير الحقيقي يكون حيث لا يصل الزائر: **مخزن أسرار Cloudflare** يخزّن المفتاح
> مشفَّراً ولا يعرضه حتى لصاحب الحساب بعد حفظه؛ يقرأه الخادم وقت التنفيذ فقط.

---

## ⚠️ قبل كل شيء: أنشئ مفتاحاً جديداً

أي مفتاح مرّ في محادثة أو رسالة أو لقطة شاشة يُعدّ مكشوفاً. أنشئ مفتاحاً جديداً من
[Google AI Studio](https://aistudio.google.com/apikey) واحذف القديم، وضع **الجديد وحده**
في أسرار البوّابة. المفتاح لا يوضع في هذا المستودع أبداً — المستودع علنيّ.

## الطريقة ١ — من لوحة Cloudflare (بلا أي أدوات)

1. أنشئ حساباً مجانياً في [dash.cloudflare.com](https://dash.cloudflare.com)
   (الخطة المجانية: 100,000 طلب يومياً — أكثر من كافية).
2. من القائمة: **Workers & Pages ← Create ← Create Worker** — سمِّه مثلاً
   `sadeed-gateway` واضغط **Deploy**.
3. اضغط **Edit code**، احذف الشيفرة الافتراضية، والصق محتوى
   [`gateway/worker.js`](worker.js) كاملاً، ثم **Deploy**.
4. من صفحة الـ Worker: **Settings ← Variables and Secrets ← Add**:
   - الاسم: `GEMINI_API_KEY` · النوع: **Secret** · القيمة: مفتاحك الجديد.
   - (اختياري) `ALLOWED_ORIGINS` نصاً عادياً إن أردت السماح لمصادر إضافية.
5. انسخ رابط الـ Worker — سيكون بصيغة:
   `https://sadeed-gateway.<حسابك>.workers.dev`

## الطريقة ٢ — من سطر الأوامر

```bash
npm i -g wrangler
wrangler login
cd gateway
wrangler deploy
wrangler secret put GEMINI_API_KEY      # ألصق المفتاح عند السؤال — لا يُكتب في ملف
```

## الربط بالمنصّة (خطوة واحدة)

افتح [`assets/site-config.js`](../assets/site-config.js)، أزل التعليق وضع رابطك:

```js
window.SADEED_SITE_LLM = {
  enabled: true,
  provider: "gemini",
  geminiModel: "gemini-flash-latest",
  geminiBase: "https://sadeed-gateway.<حسابك>.workers.dev/v1beta/models/",
};
```

ادفع التغيير (أو أعطِ الرابط لمساعد النشر ليضعه). من تلك اللحظة: كل زائر يجد
التوليد **مفعّلاً تلقائياً بلا أي مفتاح**، ويبقى لكل مستخدم أن يبدّل المزوّد أو
يضع مفتاحه الخاص من ⚙ الإعدادات (تفضيلاته تغلب إعداد المنصّة).

## التحقّق

```bash
curl -sS "https://sadeed-gateway.<حسابك>.workers.dev/v1beta/models/gemini-flash-latest:generateContent" \
  -H 'Origin: https://hanihalsulami.github.io' -H 'Content-Type: application/json' \
  -d '{"contents":[{"parts":[{"text":"قل: مرحبا"}]}]}'
```

ردّ JSON فيه نصّ = البوّابة تعمل والمفتاح يُحقن خادمياً.

## حدود الحماية — بصراحة

- **قفل المصدر (Origin)**: البوّابة لا تخدم إلا طلبات متصفّح قادمة من موقع المنصّة.
  يصدّ هذا تضمين بوّابتك في مواقع أخرى، لكنه **لا يمنع** من يستدعيها مباشرةً من
  خارج متصفّح منتحلاً الترويسة — فالمفتاح محميّ دائماً، أمّا **حصّته** فمكشوفة لمن
  تعمّد. سقف الضرر: حصّة Gemini المجانية وحدود Cloudflare اليومية.
- **نماذج ومسارات محصورة**: نداءا التوليد فقط، ولنماذج Gemini المعلنة فقط،
  وحجم الطلب مسقوف — فلا تُستعمل البوّابة وكيلاً عاماً.
- إن أردت لاحقاً ميزانية يومية صارمة أو رمز دخول للفريق، فكلاهما إضافة صغيرة
  على الـ Worker — اطلبها.
