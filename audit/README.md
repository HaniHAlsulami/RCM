# تتبّع السلوك والاستجابة (Audit Trail) — سجلّ تراكمي في Google Sheets

تجمع هذه الميزة بيانات جلسات التنبؤ واستجابة المستخدمين للإنذارات — **من جميع
الأجهزة** — في ملف Google Sheets على حسابك، عبر تطبيق ويب **Google Apps Script**
(لا خادم ولا قاعدة بيانات). ثم تعرضها المنصّة في تبويب **«🛡 لوحة القيادة»**
المحمي برقم سري.

## ما الذي يُسجَّل؟

| العمود | معناه |
|---|---|
| التاريخ والوقت | ختم الخادم لحظة الاستلام |
| الرقم المرجعي | معرّف جلسة عشوائي (NA-…) — الجلسة تبدأ بأول تنبؤ وتنتهي بالاستجابة |
| المرحلة | approvals (الموافقات) / claims (المطالبات) |
| الخطر الأولي % | احتمال عدم الاكتمال عند **أول** تنبؤ في الجلسة |
| الخطر النهائي % | الاحتمال عند تسجيل الاستجابة (بعد أن حسّن المستخدم مدخلاته) |
| قيمة الفاتورة | بالريال |
| نوع الاستجابة | `prediction` (فتح جلسة) · `applied` (طبّق الإجراء) · `ignored` (تجاهل) |
| معرف الجهاز | معرّف عشوائي ثابت للمتصفح — **بلا أي هوية شخصية** |

لا يُرسَل اسم مريض ولا رقم هوية ولا أي معرّف شخصي إطلاقاً.

## خطوات التشغيل (٥ دقائق، من المتصفّح فقط)

1. **أنشئ ملف Google Sheets جديداً** على حسابك في Google Drive
   (سمِّه مثلاً `Namaa Audit Trail`). لا تحتاج لتجهيز أعمدة — تُنشأ تلقائياً.

2. من الملف افتح **Extensions ← Apps Script**، امسح المحتوى الافتراضي،
   وألصق محتوى **`audit/Code.gs`** كاملاً، ثم احفظ (Ctrl+S).

3. **انشره تطبيقَ ويب**: Deploy ← **New deployment** ← نوع **Web app**:
   - **Execute as:** `Me` (حسابك)
   - **Who has access:** `Anyone`
   - اضغط Deploy ووافق على الأذونات (تحذير Google الأصفر طبيعي لأن السكربت
     خاص بك — اختر Advanced ← Go to project).

4. **انسخ رابط Web app URL** (ينتهي بـ `/exec`) وضعه في المنصّة، ملف
   **`assets/site-config.js`**:

   ```js
   window.NAMAA_AUDIT = {
     url: "https://script.google.com/macros/s/XXXXXXXX/exec",   // ← رابطك هنا
   };
   ```

5. ادفع التغيير إلى GitHub — انتهى. كل زوّار المنصّة سيبدأ تسجيل جلساتهم
   واستجاباتهم في الشيت، وتبويب «🛡 لوحة القيادة» سيعرض المقاييس التراكمية.

> **تعديل السكربت لاحقاً؟** بعد أي تغيير في Code.gs انشر **إصداراً جديداً**:
> Deploy ← Manage deployments ← ✏ ← Version: New version — وإلا بقي الرابط
> يخدم النسخة القديمة.

## لوحة القيادة والرقم السري

- التبويب «🛡 لوحة القيادة» يظهر في صفحتي الموافقات والمطالبات.
- الرقم السري الافتراضي: **`Admin2026`** — غيّره فوراً: نفّذ في Console المتصفح
  على أي صفحة من المنصّة:

  ```js
  RCMAudit.hash("رقمك الجديد").then(console.log)
  ```

  وضع الناتج في `site-config.js`:

  ```js
  window.NAMAA_AUDIT = { url: "…", pinHash: "الناتج هنا" };
  ```

## حدود الحماية — بصراحة

- **الرقم السري حاجز تنظيمي لا حماية تقنية**: الموقع ثابت وكل ما فيه مقروء،
  ورابط القراءة (GET) متاح لمن يعرفه. لا تضع في الشيت بيانات حساسة.
- حماية خفيفة إضافية اختيارية: ضع قيمة في `SHARED_TOKEN` داخل `Code.gs`
  والقيمة نفسها في `token` بـ `site-config.js` — تصدّ العبث العابر فقط.
- لماذا `text/plain` في الإرسال؟ تطبيقات Apps Script لا تدعم CORS preflight؛
  الترويسة البسيطة تجعل الطلب يمرّ دون preflight. هذا مقصود، لا خطأ.

## المقاييس المعروضة

| البطاقة | حسابها |
|---|---|
| إجمالي التنبؤات المنفَّذة | عدد صفوف `prediction` (جلسة لكل حالة) + عدد الأجهزة |
| الإيرادات المستنقَذة | Σ (الخطر الأولي − النهائي) × قيمة الفاتورة، لصفوف `applied` |
| معدل الاستجابة العام | `applied ÷ (applied + ignored)` |
| الطلبات المتجاهَلة | عدد صفوف `ignored` + قيمتها المعرّضة للخطر |
